# GoLedger 安卓端容错机制说明

## 功能概述

为保证应用在域名解析失败或 DNS 污染等网络环境下仍可正常使用，安卓端实现了**域名失败自动降级到 IP 直连**的容错机制。

---

## 工作原理

### 1. 多地址配置

在 `constants.dart` 中配置主地址和备用地址列表：

```dart
static const String baseUrl = 'http://www.olraingin.com:8080';  // 主地址（域名）

static const List<String> fallbackUrls = [
  'http://115.190.125.177:8080',  // 备用地址1（IP直连）
  'http://10.0.2.2:8080',         // 备用地址2（模拟器回环，仅开发用）
];
```

### 2. 自动降级流程

```
用户发起请求
    ↓
使用主地址 (域名)
    ↓
请求失败？
    ├─ 否 → 返回结果 ✓
    └─ 是 → 判断错误类型
            ↓
        连接超时/网络错误？
            ├─ 否 → 返回错误
            └─ 是 → 切换到备用地址1 (IP)
                    ↓
                重试请求
                    ↓
                成功？
                    ├─ 是 → 缓存可用地址 → 返回结果 ✓
                    └─ 否 → 继续尝试备用地址2...
```

### 3. 触发条件

以下情况会触发自动切换：
- `DioExceptionType.connectionTimeout` — 连接超时
- `DioExceptionType.receiveTimeout` — 接收超时
- `DioExceptionType.connectionError` — 连接错误
- `DioExceptionType.unknown` — 未知网络错误

**不会触发切换的情况**：
- HTTP 4xx/5xx 业务错误（说明服务器可达，只是业务逻辑错误）
- 401 未授权（正常的登录态失效）

### 4. 地址缓存

成功连接后，当前可用地址会保存到 `SharedPreferences`：
- Key: `current_server_url`
- 下次启动时优先使用缓存地址，减少切换次数

## 用户体验

### 正常场景
1. 用户打开 App → 使用域名 `www.olraingin.com` 访问
2. 请求成功 → 无感知，正常使用

### 域名故障场景
1. 用户打开 App → 尝试域名访问
2. 域名解析失败（DNS 污染/服务器故障）
3. **自动切换到 IP 直连** `115.190.125.177`
4. 请求成功 → 用户无感知，仅首次请求稍慢（多1-2秒）
5. 后续请求直接使用 IP，速度正常

### 完全不可用场景
- 所有地址都失败 → 显示网络错误提示
- 用户可在设置页面手动切换服务器地址（如果实现了设置页）

## 技术实现细节

### ApiClient 拦截器

```dart
onError: (error, handler) async {
  // 401 直接返回，不尝试切换
  if (error.response?.statusCode == 401) {
    TokenStorage.removeToken();
    handler.next(error);
    return;
  }

  // 网络错误时尝试切换
  if (_shouldTryFallback(error)) {
    final switched = await _switchToNextServer();
    if (switched) {
      // 用新地址重试原请求
      final response = await _dio.fetch(error.requestOptions);
      handler.resolve(response);  // 成功则直接返回
      return;
    }
  }
  handler.next(error);  // 所有地址都失败，返回错误
}
```

### 健康检查

切换地址前会先测试连通性：

```dart
Future<bool> _testServerConnection(String url) async {
  try {
    final testDio = Dio(BaseOptions(
      baseUrl: url,
      connectTimeout: const Duration(seconds: 3),
    ));
    await testDio.get('/health');  // 访问健康检查端点
    return true;
  } catch (e) {
    return false;
  }
}
```

## 配置建议

### 生产环境打包

```bash
# 主地址使用域名
flutter build apk --release --dart-define=BASE_URL=http://www.olraingin.com:8080
```

备用 IP 地址已硬编码在 `fallbackUrls` 中，无需额外配置。

### 开发环境

```bash
# 开发时可直接用 IP
flutter run --dart-define=BASE_URL=http://115.190.125.177:8080
```

---

## 注意事项

1. **备用地址需保持同步**：如果服务器 IP 变更，需更新 `constants.dart` 中的 `fallbackUrls`
2. **HTTPS 支持**：如果域名配置了 HTTPS，主地址改为 `https://www.olraingin.com`，但备用 IP 仍需保持 HTTP（除非 IP 也配了证书）
3. **健康检查端点**：后端需实现 `/health` 接口（当前已实现），返回 200 即可
4. **缓存清理**：如果需要强制重置为主地址，调用 `TokenStorage.clearCurrentServerUrl()`
